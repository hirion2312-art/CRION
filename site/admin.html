처음 한 번: GitHub 열쇠 연결

이 페이지는 CRION 저장소의 작품 목록·공지·소통 설정을 고쳐서 바로 배포해요. 고칠 권한을 확인하려고 GitHub '열쇠(토큰)'가 한 번 필요해요. 열쇠는 이 컴퓨터의 브라우저에만 저장돼요.

  1. GitHub 열쇠 만들기 페이지를 열어요 (GitHub 로그인 상태).
  2. Token name: crion-admin · Expiration: 1 year
  3. Repository access: Only select repositories → CRION 선택
  4. Permissions → Repository permissions: Contents = Read and write, Actions = Read-only
  5. 맨 아래 Generate token → 나온 github_pat_… 글자를 복사해서 아래에 붙여넣어요.

서버 연결 (CRION 계정 · 기록 동기화 · 게시판 · 신고함)

무료 Supabase 서버를 한 번 만들어 연결하면 열려요. 컴퓨터를 켜 둘 필요 없고, 서버는 Supabase가 돌려요. 아래 순서대로 하고 마지막에 연결 점검 → 저장하고 배포.

확인 중
  1. Supabase 새 프로젝트 (GitHub로 가입) → 이름 crion, Region Northeast Asia (Seoul), 데이터베이스 비밀번호는 아무거나(메모) → Create. 1~2분 기다려요.
  2. 왼쪽 Authentication → Sign In / Providers: Allow anonymous sign-ins 켜기 · Email 안의 Confirm email 끄기 → Save.
  3. Authentication → URL Configuration: Site URL 과 Redirect URLs 에 https://hirion2312-art.github.io/CRION/reset.html 넣기 (비밀번호 찾기 메일용).
  4. Authentication → Users → Add user → Create new user: 히리온 관리자 이메일·비밀번호, Auto Confirm User 체크.
  5. SQL Editor → New query 에 설계도를 붙여넣고 Run
    4번에서 만든 계정이 자동으로 관리자가 돼요. 나중에 설계도가 바뀌면 이것만 다시 Run 하면 돼요.
  6. Project Settings → API Keys 에서 Publishable key(sb_publishable_…) 또는 Legacy 탭의 anon public(eyJ…)을 복사, Project Settings → Data API(또는 Connect)에서 Project URL 을 복사해 아래에 붙여 넣기. secret · service_role 키는 절대 넣지 마세요.

홈 슬라이드 · 오늘의 추천작

앱 홈 맨 위에서 6초마다 넘어가는 큰 배너예요. 사진은 가로 16:9 (1600×900 권장). 연결한 작품의 플레이·작품 정보 버튼이 같이 나와요.
하나도 없으면 앱이 홈 추천 작품 + 플레이팩 작품으로 자동으로 만들어요. 왼쪽 ⠿ 를 잡고 끌어서 순서를 바꿔요.

카테고리

앱 홈 작품 목록 위에 나오는 칸이에요. 전체(플레이팩 작품이 맨 위)와 플레이팩 칸은 자동이에요. 작품마다 아래 작품 목록에서 여러 개 고를 수 있고, 작품이 하나도 없는 칸은 앱에 안 보여요.

작품 목록

앱 홈에 보이는 작품이에요. 앱은 작가 프로필에서도 작품을 자동으로 찾지만, 여기 적은 이름·장르·썸네일이 우선이에요.
주소는 크랙 작품 페이지 주소, 썸네일은 이미지 올리기 또는 이미지 주소. 홈 추천을 고른 작품은 슬라이드가 비었을 때 맨 앞에 나와요. 왼쪽 ⠿ 를 잡고 끌어서 순서를 바꾼 뒤 배포하기를 누르면 저장돼요. 음악은 그 작품을 플레이하는 동안 반복 재생돼요(Suno mp3).

공지

앱 홈 맨 위에 띄울 한 줄 공지예요. 비우면 안 보여요. 플레이어가 닫으면 그 공지는 다시 안 떠요(내용을 바꾸면 다시 떠요).

소통 설정

앱의 소통 · 신고 화면에 나오는 내용이에요. 오류 신고·건의·공략 제보는 아래 디스코드 웹후크로 바로 들어와요.

디스코드 채널 설정 → 연동 → 웹후크 → 새 웹후크 → 웹후크 URL 복사. 장난 메시지가 오면 웹후크를 새로 만들어 바꾸면 돼요.
