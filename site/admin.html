처음 한 번: GitHub 열쇠 연결

이 페이지는 CRION 저장소의 작품 목록·공지·소통 설정을 고쳐서 바로 배포해요. 고칠 권한을 확인하려고 GitHub '열쇠(토큰)'가 한 번 필요해요. 열쇠는 이 컴퓨터의 브라우저에만 저장돼요.

  1. GitHub 열쇠 만들기 페이지를 열어요 (GitHub 로그인 상태).
  2. Token name: crion-admin · Expiration: 1 year
  3. Repository access: Only select repositories → CRION 선택
  4. Permissions → Repository permissions: Contents = Read and write, Actions = Read-only
  5. 맨 아래 Generate token → 나온 github_pat_… 글자를 복사해서 아래에 붙여넣어요.

작품 목록

앱 홈에 보이는 작품이에요. 앱은 작가 프로필에서도 작품을 자동으로 찾지만, 여기 적은 이름·장르·썸네일이 우선이에요.
주소는 크랙 작품 페이지 주소, 썸네일은 이미지 올리기 또는 이미지 주소. 홈 추천을 고른 작품이 앱 홈 맨 위 큰 배너에 나와요. 음악은 그 작품을 플레이하는 동안 반복 재생돼요(Suno mp3).

공지

앱 홈 맨 위에 띄울 한 줄 공지예요. 비우면 안 보여요. 플레이어가 닫으면 그 공지는 다시 안 떠요(내용을 바꾸면 다시 떠요).

소통 설정

앱의 소통 · 신고 화면에 나오는 내용이에요. 오류 신고·건의·공략 제보는 아래 디스코드 웹후크로 바로 들어와요.

디스코드 채널 설정 → 연동 → 웹후크 → 새 웹후크 → 웹후크 URL 복사. 장난 메시지가 오면 웹후크를 새로 만들어 바꾸면 돼요.

소식

업데이트·신작·이벤트 소식. 최신 날짜가 위에 보여요.

앱 새 설치 파일

작품·공지·화면 수정은 위 배포하기만으로 이미 설치된 앱에 들어가요. 여기는 Claude가 "설치 파일을 새로 만들어야 해요"라고 할 때만 눌러요. 약 10분 뒤 다운로드 링크가 새 버전으로 바뀌어요.
