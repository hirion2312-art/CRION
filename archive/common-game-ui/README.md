# 보관: 공용 게임 화면 (화면 엔진 0.3.14 시점)

2026-10-25 히리온 결정으로 앱에서 뺐다. 크랙 응답을 읽어 배경·대사창·상태창·선택지가 있는 게임 화면으로 다시 그리던 공용 인터페이스.
**나중에 작품별 플레이팩(전용 인터페이스)을 만들 때 기반으로 쓴다.** 앱 안에서는 지금 쓰지 않는다.

## 들어 있는 것
- `renderer/` 당시 화면 엔진 전체
  - `reply.js` 응답 → 장면(대사/서술)·상태창(칩·게이지)·선택지 해석, 그림 순서 처리 (시험 19개)
  - `crack-preload.js` 크랙 페이지에서 응답 읽기: 보낸 뒤 새 글자 추적 + 응답 상자 모양 학습, 대화 칸(입력창 세로 줄)만 읽기, 프롤로그 읽기, 댓글 칸 오전송 방지, 작품 소개 페이지 버튼
  - `app.js` 게임 무대(그림 한 장 꽉 차게 순서대로, 다음 그림까지 유지), 대사창 타자 효과, 쓰는 중 기다림 화면(진행 막대·카드), 선택지, 옆 패널(상태·인물·앨범·명대사), 단축 문장, 별표, 몰입 모드
  - `store.js` 작품별 기록 / `catalog.js`·`catalog-extract.js` 작가 프로필 자동 수집(실제 크랙에서 남의 작품을 섞어 와서 중단)
- `test/` 당시 시험과 가짜 크랙 화면들(fakecrack·fakedetail·fakeprofile*)

## 알려진 한계 (다시 쓸 때 먼저 볼 것)
- 실제 크랙 화면 구조로 검증하지 못했다. 크랙 '화면 진단 복사' 결과로 `crack-rules.js` 선택자를 확정하는 것부터.
- 작가 프로필 자동 수집은 실제 프로필에서 다른 작가 작품·중복을 가져왔다. 다시 쓰려면 실제 페이지 구조(진단)를 먼저 받을 것.
