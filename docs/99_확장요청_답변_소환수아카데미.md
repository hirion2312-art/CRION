## 이 세션에서 바꿔야 할 것
1. **메인 프롬프트가 6965/7000자** — 응답 끝 `【CRION】` 블록(429자)을 넣으려면 04_확인표 02 ②의 14곳 압축이 먼저 필요. 블록 없이도 상태창만으로 배경·위기 fx·파트너 카드는 동작함. BGM은 장소 기본곡으로 대체됨.
2. 대사 표식 `【이름|표정】"대사"`은 선택. 안 쓰면 `이름 "대사"` 형태에서 등장인물만 읽음.
3. 실제 이미지·BGM 파일은 팩의 `assets/` 폴더에 manifest 이름 그대로 넣어야 함. 없으면 화면에는 이름표 자리 표시가 나옴.
4. 크랙 화면 구조는 아직 실측 전. 앱 설정의 "화면 진단 복사"를 한 번 붙여 주면 맞춰 줌.
