## 2. 소환수 아카데미 핵심 사양
- 모드 `hybrid`. 정체성: 에테르나 신입생의 **「학생 수첩」**.
- 테마: accent `#d9b25f`, bg `#0e1432`, text `#f2e9d4`, textSub `#a3abcc`. 속성색 화 `#ff7a45` 수 `#4aa8ff` 풍 `#6fe0b5` 지 `#b08a5a` 빛 `#ffd86b` 어둠 `#8a6bd6` 무 `#c9ced9`. 글꼴은 Black Han Sans(제목)·Noto Sans KR(HUD)·Gowun Batang(서술)만.
- 상태창은 **글자 패턴으로 읽는다**: 날짜·장소·학생·기숙사·돈·아이템·소환수(이름·단계·Lv·HP·XP·능력치·기술4·상태이상)·계약 n/6·도감 n/80·배지 n/7·의뢰·다음 일정·전투창(`⚔️ … vs …`, `▶ 행동 → 💥 -n`). 샘플은 `04_확인표.md`.
- 숨은 값(호감·유대)은 숫자로 절대 노출하지 않는다.
- 응답 표식: `【이름|표정】"대사"`, 끝의 `【CRION】 bg= bgm= sprites= cg= fx= hud.*= choices= 【/CRION】`. **표식을 지워도 글이 읽혀야 한다(폴백).**
- id: bgm `opening partner academy field daily rival ending`(전투·보스·승리·진화·흑일 곡은 음원이 생기면) / fx `shake flash vignette_red vignette_dark fog sparks dim heartbeat glitch` / cg `summon evo1 evo2 well1~3 badge black raid cup leg1 leg2 master dex`.
- 선택지 버튼은 **입력창에 채우기만** 한다. 자동 전송 금지.
- 팩 용량 150MB 이하(입화는 세로 960px 이하·png 팔레트 압축).

## 3. 만들 것 (결과물)
`packs/hirion.summoner-academy/` (이 id는 manifest의 `id`와 같게)
- `manifest.json` — `packs/README.md`의 필드(id, name, version, workId 또는 workUrl, summary, desc, author, tags, cover, previews, ui, minEngine) + 규격 v2 칸(theme, assets, hud, fxMap …). 처음엔 `manifest_stage1.json`을 기반으로.
- `ui.html` — 스토어 미리보기용 단독 화면(가짜 대화로 학생 수첩 모습 보여 주기, `<meta charset="utf-8">` 필수)
- `assets/` — 1단계 이미지 (아래). 없는 이미지는 화면에 이름표 자리 표시.
- 화면 엔진 쪽 코드(팩 실행기): `src/renderer/` 안에 새 파일로 추가 (예: `packrun.js`), 기존 파일은 최소 수정.
- `npm test`용 시험 추가 (파서가 `04_확인표.md` 샘플 3턴을 올바르게 읽는지 — 가장 좋은 회귀 시험).

## 4. 단계 계획 (한 번에 다 하지 말 것)
1. **0단계(확인)**: 히리온에게 "화면 진단 복사" 결과 받기. 팩 설치 방식(껍데기 변경 필요 여부) 결정 → 필요하면 히리온 허락.
2. **1단계(최소 플레이)**: 팩 설치/삭제/업데이트 + 상태창 파싱 + 배경 자동 선택 + 파트너 카드 + 시간표 띠 + 선택지 버튼 + 폴백(팩 꺼도 크랙 화면 정상). 이미지는 기존 배경 13장 + 주연 입화 6명(마가렛·레이먼드·카일·브루노·세라·이리스) + UI 5종 + 아이콘 13 + CG 2 + 팩 아이콘·타일 (`manifest_stage1.json`).
3. **2단계**: 전투 패널·카드 뒤집기·나머지 입화·지도/도감 모달·돈/아이템 아이콘.
4. **3단계**: 나머지 CG·영상·BGM(전투/보스/흑일).
이미지 신규 279장(1단계 66 / 2단계 172 / 3단계 41 + 영상 3)은 히리온이 만든다. AI는 파일명·폴더 규칙(`bg/cg/ti/map`=webp, `sp/ic/ui`=png, 전부 `assets/`)만 안내한다.

## 6. 반드시 지킬 규칙
- 크랙에 **자동 반복 전송·매크로 금지**. 사용자 클릭 1번 = 전송 1번. 로그인 정보 취급 금지.
- `config/works.json`, `config/thumbs/`, `config/bgm/` 은 건드리지 않는다(히리온이 관리). 작업 전 `git pull`.
- 크랙·뤼튼 화면을 흉내 내는 공개 페이지 금지.
- 반영 절차: `src/renderer`만 수정 → `engine.json` version +1 (껍데기가 필요하면 `minShell`·`package.json` version도) → `npm test` → 화면이면 `python3 test/ui/run.py` 스크린샷 확인 → main push → Actions "업데이트 배포" 초록 확인 → 히리온에게 한두 줄 + "앱 재시작하면 적용".
- 커밋 메시지는 한국어, 세션이 지정한 공동 작성자 줄을 끝에 붙인다.
- 일 끝나면 이 문서와 `CLAUDE.md`, `packs/README.md`를 현재 상태로 갱신하고, Project 「게임제작」에도 `project_write`로 저장.
