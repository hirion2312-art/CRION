# CRION 업데이트 방식 (v0.2)

## 왜 바꿨나
이전: 내가 zip을 받아 → 폴더에 덮어쓰고 → npm install → 팩 재설치. 작품 하나 고칠 때마다 이걸 반복해야 했음.
이제: **앱 본체를 다시 설치하지 않고**, 바뀐 부분만 자동으로 받는다.

## 3층 구조
| 층 | 내용 | 바뀌는 빈도 | 어떻게 배포 |
|---|---|---|---|
| 본체(Shell) | Electron 창, 설치·보안 | 거의 안 바뀜 | .exe/.dmg 다시 설치 |
| 화면 엔진 | `src/renderer/*` 게임 화면·파서 | 가끔 | 자동 다운로드, 다음 실행부터 적용 |
| 팩 | 작품별 manifest·이미지·BGM | **자주** | 자동 다운로드, 바뀐 파일만 |

## 안전장치
- 업데이트 목록 `index.json`은 비밀 열쇠로 **서명**. 앱은 공개 열쇠로 확인하고 틀리면 거부.
- 모든 파일 **sha256 확인**. 깨졌거나 바뀐 파일이면 설치 안 함.
- 새 폴더를 다 받은 뒤 한 번에 교체. 실패하면 기존 것이 그대로 남고, 직전 버전은 `.prev`로 보관.
- 새 화면 엔진이 25초 안에 정상 시작하지 못하면 자동으로 내장 엔진으로 되돌림.

## 내가 하는 일 (한 번만)
1. GitHub 저장소 만들기 → Settings > Pages > Source: GitHub Actions.
2. `npm run keygen` → `keys/private.pem` 생성. 내용을 저장소 Secrets `CRION_SIGN_KEY`에 붙여넣기. (private.pem은 절대 공개 금지, 백업 필수)
3. `config/app.json`의 `registryUrl`에 `https://<아이디>.github.io/<저장소>/index.json` 입력.
4. 본체 빌드(태그 `v0.2.0` push) → exe/dmg를 팔로워에게 배포. 이 한 번이 마지막 설치.

## 평소 작업 (작품 업데이트)
1. 작품 세션이 준 폴더(manifest + assets)를 `packs/<팩id>/`에 덮어씀.
2. `npm run check` → 빠진 파일·안 쓰는 파일 확인.
3. manifest의 `version`을 올리고 main에 push.
4. Actions가 자동으로 서명·배포. 팔로워 앱은 켜 있는 동안 30분마다(또는 설정의 "지금 확인") 확인하고 바뀐 파일만 받음.

로컬 확인만 할 땐 `npm start`. 팩은 앱 안에서 제거 후 다시 설치하면 새 파일이 반영됨.

## 언제 본체를 다시 배포하나
`main.js`·`preload-host.js` 변경, Electron 버전 변경, `engine.json`의 `minShell`·`apiLevel`이 올라갈 때. 이 경우 앱이 "새 설치 파일이 필요해요" 안내를 띄움. 평소엔 해당 없음.

## 용량 주의
GitHub Pages는 사이트 1GB 권장 한도. 이미지는 webp, BGM은 mp3 128kbps로 줄이기. 한도가 문제되면 Cloudflare R2/Pages 등으로 `registryUrl`만 바꾸면 됨.

## 명령 요약
`npm run setup` Electron 설치 복구(맥 포함) · `npm run check` 팩 점검 · `npm run keygen` 서명 열쇠 · `npm run registry -- <주소>` 목록 만들기 · `npm test` 시험
