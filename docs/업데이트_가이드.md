# CRION 업데이트 방법

설치된 팔로워 앱에 무언가를 반영하는 길은 세 가지예요. 대부분은 1번, 가끔 2번, 아주 가끔 3번.

| 무엇을 바꾸나 | 누가 | 어떻게 | 팔로워 앱에 들어가는 시점 |
|---|---|---|---|
| 작품 추가·주소·썸네일·순서·숨기기, 공지 | 히리온 | **관리 페이지**에서 고치고 **배포하기** | 1~2분 뒤 서버 반영 → 앱이 30분 안에(또는 홈의 목록 새로고침, 재시작) |
| 화면·인식 개선 (게임 화면, 크랙 인식 규칙) | Claude 세션 | 저장소 `src/renderer` 수정 → push | 앱이 받아 두고 **다음 재시작** 때 적용 |
| 앱 본체 (창, 보안, 설치 방식) | Claude 세션이 말하면 히리온이 버튼 | 관리 페이지 **새 설치 파일 만들기** | 약 10분 뒤 다운로드 링크가 새 버전. 팔로워는 새로 받아 설치 |

## 1. 관리 페이지 (히리온)

주소: **https://hirion2312-art.github.io/CRION/admin.html**

처음 한 번만 GitHub 열쇠(토큰)를 만들어 붙여 넣어요. 페이지에 순서가 그림처럼 적혀 있어요.
- Repository access: CRION 하나만
- Permissions: Contents = Read and write, Actions = Read-only
- 열쇠는 그 브라우저에만 저장돼요. 다른 컴퓨터에서는 다시 붙여 넣으면 돼요. 1년 뒤 만료되면 새로 만들어요.

할 수 있는 것
- 작품: 제목, 장르 한 줄, 크랙 주소, 썸네일(이미지 올리기 또는 주소), 순서, 숨기기, 삭제, 추가
- 공지: 앱 홈 맨 위 한 줄 + 자세히 링크
- 배포 기록: 초록 점이면 서버 반영 끝
- 새 설치 파일 만들기: 버전을 하나 올려 Windows·Mac 설치 파일을 새로 만듦

참고
- 앱은 작가 프로필에서도 작품을 하루 한 번 자동으로 찾아요. 관리 페이지에 적은 값이 우선이에요.
- 프로필에서 찾은 작품을 앱에서 빼고 싶으면 **삭제**가 아니라 **숨기기**.

## 2. 화면 개선 (Claude 세션)

Claude에게 "크리온에 반영해" 또는 "크리온 업데이트해"라고 하면 돼요. 세션은 아래 절차를 따라요.

1. 저장소 `hirion2312-art/CRION`을 붙이고 받는다.
2. `src/renderer/` 만 고친다 (화면 엔진). `src/main.js`·`src/preload-host.js`를 고쳐야 하면 3번 길이라고 히리온에게 먼저 말한다.
3. `src/renderer/engine.json`의 `version`을 하나 올린다 (예: 0.3.1 → 0.3.2). 안 올리면 앱이 안 받는다.
4. `npm test`가 통과하는지 확인하고, 화면을 바꿨으면 `python3 test/ui/run.py`로 스크린샷을 본다.
5. main에 push → GitHub Actions "업데이트 배포"가 자동 실행 → 초록이면 끝.

크랙 인식이 틀렸을 때(응답을 못 읽음, 보내기가 안 됨, 작품 목록이 비어 있음): 플레이어가 앱 설정의 **화면 진단 복사 / 목록 진단 복사** 결과를 주면, 세션이 `src/renderer/crack-rules.js`(선택자)나 `catalog-extract.js`를 고쳐 2번 길로 내려보낸다.

## 3. 새 설치 파일

`src/main.js`, `src/preload-host.js`, `package.json`의 Electron 버전처럼 앱 본체가 바뀌면 필요해요. 화면 엔진의 `minShell`을 새 버전으로 올렸다면 옛 앱은 그 엔진을 받지 않고 "새 설치 파일이 필요해요" 안내를 띄워요.
- 히리온: 관리 페이지 → **새 설치 파일 만들기**
- 또는 Claude 세션이 `package.json` version을 올려 push

## 안전장치 (자동)
- 받은 파일마다 sha256 확인, 깨지면 설치 안 함
- 새 폴더를 다 받은 뒤 한 번에 교체, 실패하면 기존 그대로
- 새 화면 엔진이 25초 안에 안 뜨면 그 버전을 막고 앱 안 엔진으로 되돌림
- (선택) 서명: `npm run keygen` → 저장소 Secrets `CRION_SIGN_KEY` → 새 설치 파일. 서명을 켜면 위조된 업데이트를 거부해요.
