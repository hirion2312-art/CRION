# CRION — 히리온 작품 전용 크랙 클라이언트 (v0.3)

히리온의 크랙 작품을 채팅창 대신 **게임 화면**으로 플레이하는 Windows·macOS 앱.

## v0.3에서 바뀐 것
- 작품별 전용 팩을 모두 걷어내고 **공용 게임 화면** 하나로 모든 작품을 플레이
- CRION 입력창에서 보내면 크랙에 그대로 전송, 응답이 **쓰이는 중에도** 대사창에 흐름
- 응답 속 그림은 **자기 자리**에서만 보이고, 다른 인물이 말하면 내려감
- 상태창(구분선 사이, 코드 상자, 끝부분 수치 줄)을 옆 패널 카드·게이지로 정리
- 선택지(번호 목록, 💡 줄) 버튼, 지난 대화 기록, 재생성, 크랙 원본 화면 전환
- 작품 목록은 작가 프로필(`config/works.json`의 `creatorUrl`)에서 썸네일과 함께 **자동으로** 읽어 옴

## 실행 (개발용)
```
npm install
npm run setup   # Electron 설치가 덜 됐을 때(특히 맥)
npm start
```

## 처음 플레이
1. 작품 카드를 누르면 크랙 원본 화면이 열린다 → 로그인하고 대화 시작
2. 대화창이 열리면 자동으로 게임 화면으로 바뀐다
3. 홈의 **목록 새로고침**: 로그인 뒤 한 번 누르면 작품 목록·썸네일을 프로필에서 다시 읽는다

## 인식이 틀릴 때
크랙 화면 구조는 실측 전이라 '모양'으로 찾는다. 틀리면 설정에서
- **화면 진단 복사** (플레이 중) — 응답·입력창 인식 확인용
- **목록 진단 복사** — 작품 목록 인식 확인용

을 눌러 보내 주면 `src/renderer/crack-rules.js`·`catalog-extract.js`를 고쳐 **화면 엔진 업데이트**로 내려보낸다(앱 재설치 불필요).

## 업데이트 구조
`docs/업데이트_가이드.md` 참고. `src/renderer`(화면 엔진)와 `config/works.json`(작품 목록)이 main에 올라가면 GitHub Actions가 서버(GitHub Pages)에 올리고, 앱은 30분마다 받아 간다.

## 시험

npm test                 # 응답 해석 + 업데이트 도구
